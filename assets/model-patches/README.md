# Equipment region masks, 0.3.16

These JSON files contain numerical UV polygons selected from Divine Collada exports,
not painted diffuse textures or native geometry. The build rasterizes them to linear
1024px RGBA masks with two-pixel gutters. Native VT albedo, normal and material maps
remain in use.

- Carsomyr: R = gold crossguard, blade-base protection and pommel; G = red grip.
  Selection: triangle center `z > -0.48`, except the grip defined by
  `-0.058 < z < 0.24 and abs(x) < 0.035`. Unselected steel keeps its native texture.
- Dragon's Breath: R = red-copper head/spike and butt cap. Selection:
  triangle center `z < -1.03 or z > 0.40`. Unselected shaft keeps its native texture.

Native meshes: `WPN_GTY_Greatsword_Vlaakith_A.GR2` and `WPN_HUM_Halberd_A_2.GR2`.
UV selections use LOD0; all existing LOD objects keep the same private material.
Source Collada SHA256 values are stored in each JSON. The exported meshes themselves
are deliberately absent from this repository.

To regenerate after exporting the corresponding native meshes with Divine:

```powershell
python authoring/patch_visuals_0316.py --project-root . --carsomyr-dae C:/exports/carsomyr.dae --halberd-dae C:/exports/halberd.dae
```

Normal builds need only Pillow and the saved JSON; no Collada or numpy dependency.
Colors are explicit `Color_01/02/03` overrides of the stock
`Base_MSK_AlphaTest_VT` shader. No native resource is overwritten.

In 0.3.17 the Dragon's Breath mask is retained for history only and is NOT staged or used. The halberd material is restored exactly to 0.3.15.

## 0.3.18

The new `CharonsClaw-regions-0318.json` and `DragonsBreath-regions-0318.json` are complete RGB selections generated by `authoring/weapon_regions_0318.py`. They use 2048px masks, explicit R/G/B colors and repeated UV tiles. Claw: R dark blade/grip, G central crimson vein, B cool steel fittings. Halberd: R crimson shaft, G warm steel cutting surfaces, B bronze relief/fittings. Native geometry, UVs, normal and material maps remain unchanged. The original 0.3.16 halberd mask stays unused.

## 0.3.19 — Carsomyr

Current `Carsomyr-regions.json` is produced by `authoring/carsomyr_regions_0319.py`, replacing the original broad guard/langet selection. R contains the central ferrule (`abs(x)<=0.055, -0.16<z<-0.058`), lateral quillons (`abs(x)>0.055, z>-0.20`) and the approved pommel (`z>0.245`). G grip polygons are identical to 0.3.18. The 0.3.18 selection is archived in `history/0.3.18/`. Saved native UV probes check 816 blade samples and 72 longitudinal-protection samples have no gold; all 1900 quillon samples and 116 central-ferrule samples are gold. To regenerate this CURRENT mask use carsomyr_regions_0319.py with the archived mask as --previous, not the legacy export_regions selector.
