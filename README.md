# Legacy Party Armory

Исходники **0.3.1 PREVIEW** для Baldur’s Gate 3. Мод использует BG3 Script Extender (16+) и Lua. Вещи выдаются вручную действием **«Получить Legacy Party Armory»** вне боя.

Внешний рюкзак содержит наборы Paladin, Wyll — Artemis Entreri, Karlach — Infernal Viking, Minthara — Drizzt Do’Urden, Jaheira — Legacy и два набора Shadowheart (Shar/Selûne).

## Текущая версия

- 16 custom-вещей с легендарной редкостью и жёлтыми названиями; ванильные предметы не изменены.
- Карсомир: модель `f01c3f5d-c542-420f-86c5-bdddf7819e29`, отдельная маска красного хвата.
- Мерцающий, Ледяная Смерть и Коготь Харона: родные карты свечения; камень кинжала Энтрери использует кристаллический шейдер.
- Дыхание дракона: красная алебарда с выбором одной из пяти стихий.
- Джахейра: лёгкий доспех на основе Spidersilk Armour в древесной гамме.
- Утверждённый драконий визуал и прежние UUID сохранены. Броня: КБ 16 + ловкость до +2.
- Полная локализация EN/RU, английский fallback для остальных языков.

Это тестовая версия: Lua и файлы пакетов проверены, но последняя правка свечения и цветов ещё требует проверки в игре.

## Сборка из этого репозитория

Нужны Windows PowerShell/PowerShell 7 и [LSLib ExportTool / Divine](https://github.com/Norbyte/lslib/releases). Сам ExportTool и игровые архивы в репозиторий не включены.

```powershell
./Build.ps1 -Mode preview -Divine 'C:/Tools/ExportTool/Tools/Divine.exe'
./Build.ps1 -Mode final -Divine 'C:/Tools/ExportTool/Tools/Divine.exe'
```

Либо задайте путь к Divine.exe переменной `BG3_DIVINE`. Готовые пакеты появятся в `dist/`. Скрипт компилирует пять XML-банков ресурсов и XML-локализации, добавляет конфигурацию выдачи выбранного режима и упаковывает мод. Каждая сборка использует отдельную папку в `build/`.

Распакованные игровые данные, Python и исходный исследовательский workspace для этой сборки не нужны. Для запуска самого мода нужна установленная BG3 с соответствующими штатными моделями и текстурами.

## Структура исходников

- `src/` — текущие файлы мода: Lua, Stats, meta, читаемые LSX-ресурсы и XML-локализации, DDS-текстуры.
- `config/preview.json` — полный набор для примерки: 42 объекта вместе с рюкзаками.
- `config/final.json` — предварительный FINAL: custom-вещи и четыре основных красителя, 29 объектов вместе с рюкзаками.
- `config/resource-files.json` — какие LSX необходимо компилировать в LSF; GUI/meta LSX остаются текстовыми.
- `authoring/` — оригинальные Python/Lua-скрипты, которыми создавалась эта версия. Они сохранены для дальнейшей разработки и отдельно описаны ниже.
- `docs/ITEMS.md` — предметы, UUID, характеристики, палитры и предварительные статусы FINAL.
- `docs/SOURCES.md` — источники и точные игровые идентификаторы.
- `docs/TESTING.md` — проверки поведения и план примерки в игре.
- `verification/` — результаты проверок исходной сборки, её SHA256 и манифесты.

В `src` сохранены все данные, необходимые для упаковки текущей версии. `authoring` — снимок первоначального генератора: его полный повторный запуск требует извлечённых данных BG3 и прежнего Dragon Armor workspace, которые не опубликованы. Пользуйтесь корневым `Build.ps1` для самостоятельной сборки и правьте текущий мод в `src/` и `config/`. Подробности: [BUILDING.md](docs/BUILDING.md).

## Установка

Импортировать PREVIEW `.pak` в Vortex/BG3 Mod Manager **вместо** предыдущего DenimDragonArmor/Legacy Party Armory, развернуть порядок загрузки и полностью перезапустить игру. Пакеты PREVIEW и FINAL одновременно не включать: у них один UUID модуля `5d96794a-b84b-4bf7-afaa-74063318d3a6`.

После загрузки сохранения использовать действие «Получить Legacy Party Armory» и открыть созданный рюкзак. При загрузке, начале новой игры и смене уровня предметы автоматически не выдаются. Повторное ручное применение создаёт ещё один комплект.

FINAL сейчас является конфигурацией для дальнейшего отбора, а не утверждённым релизом.
