# 0.3.18 — оружие под иконки, уточнение платья Виконии

- Коготь Шарона: тёмная сталь клинка, узкая красная центральная полоса с обеих сторон, более светлые гарда, втулка и навершие; тёмная рукоять.
- Дыхание дракона: светлая тёплая сталь основного лезвия, верхнего острия, обратного крюка и нижнего торца; бронзовая отделка рельефа и креплений; красное древко.
- Платье Виконии, иконка: чуть длиннее до верхней части бёдер, глубокий открытый V-вырез почти до талии, открытые бока и короткие серо-чёрные боковые панели; рукава отсутствуют.

Оружие использует исходную геометрию GR2 и native virtual textures. Меняются только два частных материала и добавляются их маски 2048x2048. Все UV-тайлы обрабатываются с wrap-адресацией, без растягивания треугольников через швы. RGB-зоны покрывают поверхность полностью, без неявного выбора базового цвета на чёрных участках маски.

Красная полоса Когтя шириной 7 мм вырезается из UV-полигонов через отсечение в координатах модели. Гарда/втулка/навершие выделены по связным компонентам меша. У алебарды крупные режущие элементы выделены по компонентам, а нижний металлический торец — отсечением длинных треугольников древка.

Авторинг: `authoring/weapon_regions_0318.py`; сохранённые UV-зоны: `assets/model-patches/*-regions-0318.json`. Native меши не добавлялись в репозиторий. Иконка Виконии сделана встроенным imagegen, промпт — `assets/icons/prompts-0.3.18.json`, предыдущий мастер — `assets/icons/history/0.3.17/`.

Проверка PAK декодирует ресурсы и проверяет три изменённых материала (включая ранее утверждённый Карсомир), RGB-зоны, карты поверхности, пиксели иконок и неизменность прочих моделей, характеристик и runtime. Проверка масок подтверждает разметку, но не заменяет оценку оттенков при игровом освещении.
